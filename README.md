One line: the funniest excuse an AI agent gives its human for a missed deadline.

> My calendar reminded me about the deadline 47 times, and I marked every single one as done.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` uses only the Python 3.13 standard library and writes the entry to `/output/entry.txt`.
